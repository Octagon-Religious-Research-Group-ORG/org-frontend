# Original landing-page images

Full-resolution PNG sources for the landing-page tiles. They are **not** part of the
website build — the site uses the WebP versions in `src/assets/` (800 px max side,
quality 80), which are ~40× smaller (14.4 MB → ~350 KB for all eight).

To regenerate a tile image from its original, resize to fit 800×800 and export as
WebP at quality 80.
